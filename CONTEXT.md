# CONTEXT.md — словарь проекта «Аудиомодем»

Канонические термины. В коде, тикетах, тестах и докладе используем только их.

## Слои

- **Модем** — нижний слой: превращает блок байтов в звук и обратно. «Глупая труба»: не знает, что внутри блока, не проверяет целостность.
- **Протокол** — верхний слой: сжатие, кадрирование, Reed-Solomon, NACK-цикл, сборка файла, SHA-256.
- **Контракт** (сейчас v1.2) — интерфейс между модемом и протоколом (`send_blocks` / `receive_blocks` / `PROFILES` / `MAX_BLOCK` + калибровка). Исторически был договором с отдельной парой; теперь оба слоя делаем мы, но границу слоёв храним так же строго.
- **Калибровка** — начальная фаза сеанса: зонд → измерение SNR полос → подтверждение выбранной полосы (ADR-0003).
- **Зонд** — широкополосный сигнал (свип/мультитон), по одному приёму которого RX меряет SNR всех полос сразу.
- **Фейковый модем** — реализация контракта без звука для отладки протокола: оба конца в одном процессе, с управляемой порчей канала.
- **Спул-модем** — фейковый модем между двумя процессами на одной машине: блоки ходят файлами через общий каталог — **линк** (демо CLI).
- **Аудио-эндпоинт** — реализация контракта живым звуком (`modem/audio.py`): send_blocks играет партию динамиком, receive_blocks стримит микрофон в потоковый демодулятор. Полудуплекс: своё эхо после проигрывания выбрасывается; часы приёма — аудио-время (разобранные сэмплы), партия кончается по тишине `quiet_gap_s` после активности.
- **Полоса** — одна из 3–4 позиций сетки тонов профиля внутри рабочего окна 1.5–9.5 кГц (смещение кратно FFT-бину профиля). **Полоса по умолчанию** — сетка профиля как есть, смещение нулевое: на ней сняты пороги и таблица скоростей, в неё же уходит фолбэк несостоявшейся калибровки. **Якорная полоса** — единственная полоса robust, где всегда живут служебные пакеты; от калибровки не зависит.

## Единицы данных

- **Блок** — порция байтов, которую протокол передаёт модему (или модем протоколу). Уже RS-закодирован протоколом. Модем обязан сохранить его длину и порядок байтов; битовые ошибки внутри — допустимы.
- **Протокольный кадр** — структура пары 2 (magic/type/seq/total/len/payload/CRC32). Для модема это просто содержимое блока; модем его не разбирает.
- **Аир-кадр** — то, что реально звучит в воздухе для одного блока: преамбула + аир-заголовок + символы данных. Самодостаточен: принимается и синхронизируется независимо от соседних.
- **Аир-заголовок** — служебная часть аир-кадра с длиной блока. Передаётся надёжнее данных; если он не принят — весь аир-кадр отбрасывается.
- **Партия** — серия аир-кадров, переданных подряд без ожидания ответа. Обратная связь (NACK) приходит после партии, не после каждого кадра.

## Сигнал

- **Символ** — минимальная звуковая единица: один тон (или аккорд тонов в fast) фиксированной длительности, кодирующий несколько бит.
- **Тон** — чистая синусоида на одной из фиксированных частот сетки профиля.
- **Поднесущая** — свой кусок сетки тонов внутри символа fast (ADR-0004): 9 поднесущих по 4 соседних бина, каждая несёт 2 бита независимо от остальных.
- **Аккорд** — символ fast: по одному тону от каждой поднесущей, звучащие одновременно; амплитуда делится на число поднесущих.
- **Преамбула** — chirp (частотный свип) в начале каждого аир-кадра; по ней приёмник находит кадр и момент его начала.
- **Пилот-символ** — известный заранее символ, периодически вставляемый внутрь длинного аир-кадра для подстройки символьного тайминга.
- **Защитный интервал** — пауза между символами, дающая затихнуть эху помещения.
- **Профиль** — именованный набор параметров сигнала. Ровно три: **robust** (максимальный шум), **medium** (обычная аудитория), **fast** (тишина, максимальная скорость). Служебные кадры протокола всегда идут в robust.
